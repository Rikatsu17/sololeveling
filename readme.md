# Ascend — Level up your real life

Персональная web-платформа саморазвития: реальные действия, навыки и жизненные цели в спокойном тёмном интерфейсе. Оригинальный дизайн, без визуальных заимствований из Solo Leveling.

## Запуск

Требуется Node.js 20.19+.

```bash
npm install
npm run dev
```

Открыть **http://localhost:5173**. Vite проксирует `/api` на Express, порт 3001.

Production-сборка для локального использования:

```bash
npm run build
npm start
```

Открыть **http://localhost:3001**. Express обслуживает собранный frontend и API.

Первый запуск открывает демонстрационный workspace. **Sign in → Create an account** создаёт отдельный аккаунт и запускает интервью из трёх шагов. Кнопка **Make it yours** позволяет настроить локальный workspace без регистрации. Подтверждение интервью заменяет демонстрационные данные в текущем workspace вашим профилем. Начальные уровни формируются по самооценке; все уровни можно редактировать.

## Возможности

- Dashboard: общий уровень, XP, streak, задачи дня, навыки, характеристики, цель, рекомендации и недельная активность.
- Quests: Daily, Weekly, Main, Side, AI Suggested, Custom; поиск, фильтры, дата, сложность, время, связь с навыком, характеристиками и этапом цели.
- Log progress: описание действия → локальная оценка времени/навыков/XP → редактирование → подтверждение → сохранённая транзакция.
- Skills и Stats: создание, редактирование, удаление, стартовые уровни, связанные задания и история XP.
- Goals: цели с редактируемым при создании roadmap, этапами и созданием Main Quest прямо из этапа. Связанная задача автоматически закрывает этап.
- Analytics: 7/30 дней, XP, часы, выполненные действия, доля завершения, рост навыков и время по жизненным сферам.
- Timeline: действия, изменения стартовых уровней и достижения с датами.
- Achievements: реальные объёмы практики, регулярность и достигнутые цели.
- Assistant: история чата, контекст профиля, планы и добавление предложенных задач через подтверждение.
- Profile и Settings: имя, описание, ежедневный бюджет времени, уменьшение анимации и полный JSON-экспорт.
- Аккаунты: регистрация, вход, выход, смена пароля и отзыв остальных сессий. Каждый аккаунт использует отдельную SQLite-базу; пароли хешируются scrypt с индивидуальной солью. Сессии — случайные токены в HttpOnly/SameSite cookie, в базе хранится только SHA-256 токена. Есть ограничение попыток входа и проверка Origin.
- Адаптивный интерфейс, клавиатурная навигация, focus trap в диалогах, Escape для закрытия и поддержка reduced motion.

## AI: два честно обозначенных режима

**Без ключа:** локальный помощник с прозрачными правилами. Учитывает связанные навыки, цели, историю активности, доступное время и незавершённые задачи. Подбирает менее активные направления; уменьшает объём при накоплении пропусков и увеличивает при устойчивом выполнении. Принятые и пропущенные рекомендации сохраняются. Планы и roadmap — стартовые шаблоны, а не ответы языковой модели.

**С провайдером:** задайте `AI_API_URL`, `AI_API_KEY`, `AI_MODEL` в окружении сервера (см. `.env.example`). Endpoint должен принимать chat-completions JSON (`model`, `messages`) и возвращать `choices[0].message.content`. Перезапустите сервер. Сам файл `.env` автоматически не загружается; переменные нужно экспортировать, либо запустить Node с `--env-file`.

```bash
node --env-file=.env backend/server.js
```

Внешний чат получает профиль, цели, навыки, характеристики, задания, активность и последние сообщения. Модель также подключается к оценке XP и созданию roadmap. Предложенные ID, время и награды валидируются сервером; неизвестные связи отбрасываются, XP ограничены 200. Ключ остаётся на сервере. Есть таймаут и обработка ошибок провайдера. Контракт интеграции проверяется на тестовом HTTP-провайдере; реальная внешняя модель не проверялась без действующего ключа. Все действия подтверждаются пользователем.

## XP и сохранность данных

Локальный workspace хранится в `backend/data/ascend.db`. Аккаунты, сессии и отдельные базы пользователей — в `backend/data/ascend.db.accounts/`. Оба пути исключены из git. `DATABASE_PATH` и `ACCOUNTS_PATH` позволяют изменить расположение. WAL и foreign keys включены. Начисление XP, завершение задания, история навыка и дневная активность сохраняются **атомарно**. Повторное завершение одной задачи отклоняется.

- Общий уровень: 1 000 XP на уровень.
- Навык: 500 XP на уровень.
- Характеристика: 200 XP на уровень.
- Одна задача: 5–200 XP; навык получает ту же величину, каждая выбранная характеристика — 30%.
- Общий XP начисляется один раз, без суммирования наград по всем связям.
- Повторные действия с одинаковым названием за день: `base / (1 + repeats × 0.5)`.
- Изменения уровня вручную и начальная самооценка тоже записываются в `XPTransactions`, но не засчитываются как выполненная практика.
- Пропуски не уменьшают XP. Streak допускает ещё не завершённый сегодняшний день.
- Дни и streak сейчас рассчитываются по UTC.
- Daily/Weekly — категории планирования; задачи не копируются автоматически по расписанию.

Скопируйте базу через SQLite backup API либо остановите сервер перед файловой резервной копией. Экспорт из Settings содержит всю историю, включая XP-транзакции, рекомендации и прогресс навыков.

## Архитектура

```text
frontend/main.jsx       React: навигация, страницы, формы, диалоги
frontend/styles.css     Адаптивная дизайн-система
backend/server.js       Express API, валидация, транзакции
backend/accounts.js     Аккаунты, сессии, изоляция баз через AsyncLocalStorage
backend/assistant.js    Контракт внешней модели и проверка предложений
backend/domain.js       Чистая логика уровней, наград и streak
backend/db.js           SQLite schema и демонстрационные данные
backend/*.test.js       Проверки предметной логики и API
tests/platform.spec.js Браузерные проверки ключевых сценариев
```

Реестр аккаунтов: `Accounts`, `Sessions`. В каждом изолированном workspace таблицы: `Users`, `Profiles`, `Stats`, `Skills`, `SkillProgress`, `Quests`, `QuestCompletions`, `Goals`, `Milestones`, `Achievements`, `UserAchievements`, `XPTransactions`, `DailyActivity`, `AIRecommendations`, `AIConversations`, `ProgressEvents`. Связи и индексы определены в `backend/db.js`; ссылки навыков/задач на характеристики хранятся в JSON-массивах и очищаются при удалении характеристики. История XP сохраняется при удалении связанной сущности.

## Проверка

```bash
npm test
npm run test:e2e
```

Для первого запуска браузерных тестов может потребоваться `npx playwright install chromium`. E2E запускают отдельный сервер и отдельную базу `backend/data/e2e.db`, не затрагивая основной профиль. Проверяются завершение задач, оценка и редактирование XP, навыки, roadmap, чат, сохранение после перезагрузки, onboarding, мобильная навигация, регистрация и вход. API-тесты дополнительно проверяют изоляцию аккаунтов и отзыв сессий при смене пароля. Скриншоты записываются в `artifacts/`.

## Границы текущей версии

Это рабочее приложение с сервером и несколькими изолированными аккаунтами. По умолчанию сервер слушает loopback; публичное размещение не выполнялось. Для развёртывания за HTTPS-прокси задайте `HOST=0.0.0.0` и `COOKIE_SECURE=true`, настройте TLS и резервное копирование всех баз. Workspace без входа общий для посетителей данного экземпляра: для личных данных используйте отдельный аккаунт.

Email-верификация и восстановление пароля по email не реализованы — почтовый провайдер не подключён. Планировщик повторяющихся задач, мобильные push-уведомления и фоновая AI-обработка также не включены. Дни сейчас рассчитываются по UTC. Настоящий AI требует настроенного провайдера; без него доступен явно обозначенный локальный режим.
